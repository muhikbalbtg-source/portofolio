# Portofolio Muhammad Ikbal

Website portofolio pribadi saya, **Muhammad Ikbal**, mahasiswa dan web developer. Website ini menampilkan profil, pengalaman, hobi, keahlian, dan proyek yang pernah saya kerjakan.

## ✨ Fitur

- Desain modern dengan efek gradien dan animasi halus
- Mode gelap dan terang (dark/light mode)
- Navigasi satu halaman dengan bagian: Beranda, Tentang, Pengalaman, Hobi, Keahlian, Proyek, dan Kontak
- Ditulis dalam Bahasa Indonesia

## 🛠️ Teknologi yang Digunakan

- [React](https://react.dev/)
- [Vite](https://vitejs.dev/)
- [Oxlint](https://oxc.rs/docs/guide/usage/linter) untuk linting

## 🚀 Menjalankan Secara Lokal

1. Pasang dependensi

   ```bash
   npm install
   ```

2. Jalankan server pengembangan

   ```bash
   npm run dev
   ```

3. Buka `http://localhost:5173` di browser

## 📦 Build untuk Produksi

```bash
npm run build
npm run preview
```

Hasil build tersedia di folder `dist/`.
